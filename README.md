## 🔭 What I'm working on

A paid companion app for expecting and new fathers (iOS and Android, four languages): a daily task for the current week, a journal, birth preparation and the first 12 weeks with the baby.

**Under the hood:** Riverpod, go_router, Drift as the single source of truth for the UI, Firebase as a sync layer, feature-first layers (`data` / `domain` / `presentation`), and pure-Dart domain logic covered by unit tests.
